# Changelog

All notable changes are documented here.

## 1.1.0 - 2026-09-05

- Rebuilt the popup, dashboard, settings, and demo around shared light and dark themes.
- Added an interactive public preview, responsive layouts, clear loading and empty states, and keyboard navigation.
- Organized profile, filtering, AI, account, and data controls into separate settings sections.
- Added profile draft protection, case-insensitive tag deduplication, and Command or Ctrl + S to save.
- Added a real pause control and a live filter preview.
- Added 7, 14, and 30-day statistics, daily breakdowns, and CSV exports.
- Fixed double-counted ads in time estimates, overlapping settings/statistics writes, job-policy handling, and stale filtering when switching modes.
- Moved score explanations into native popovers and made blurred content inaccessible to keyboard input until revealed.
- Added explicit AI save/test actions, provider URL validation, and clearer data-deletion confirmations.
- Published the website and isolated preview through the GitHub Pages build pipeline.

## 1.0.0 - 2026-08-30

- Added local, explainable LinkedIn feed scoring and four filtering modes.
- Added personalized profiles, feedback signals, per-post overrides, and a seven-day dashboard.
- Added optional OpenAI-compatible analysis with user-approved host access.
- Added optional Supabase accounts and cross-device settings sync.
- Added safe data export, account deletion, release verification, and Chrome Web Store packaging.
