# Support

Use [GitHub Issues](https://github.com/hithere-devs/signal-linkedin/issues) for bugs and feature requests.

Before filing a bug:

1. Update to the latest release.
2. Reload LinkedIn and the extension.
3. Run the same flow with AI analysis disabled.
4. Include your Chrome version, Signal version, filtering mode, and reproducible steps.

Never post AI keys, authentication tokens, private profile data, or screenshots containing private feed content.
