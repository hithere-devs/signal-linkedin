# Signal workspace

Mode: operate. Scope: dashboard, settings, popup, and the filter demonstration.

The user delegated design and feature decisions. Primary job: understand the feed's outcomes and tune what appears, without cloud setup blocking local use.

Direction: contemporary field guide with blue annotations. Concept seed 5900966d assigned candidate 6. The bitmap, festival, instrument, arcade, origami, and cloud challengers were considered against audience identification and product clarity; the field guide preserves professional readability and a direct connection between categories and filtering. The user requested no standalone HTML report.

Approved reference: `.impeccable/mocks/01-overview-workspace.png`. Approval was delegated by the original user request. The second reference informs only the feed-control preview. The third was rejected as too ledger-heavy for first-time use.

Composition commitments: persistent left navigation, a quiet utility header, left-aligned heading and date range, one outcome strip, a wide activity chart beside a smaller threshold panel, then category and reason lists. On narrow screens navigation becomes a compact header and horizontal links, panels stack, and controls keep their labels. The popup remains a compact controller, not a miniature dashboard.

Component grammar: humanist system sans; h1 around 30px, section headings 16px, body 14px, secondary labels 12px; major panel corners 14px, controls 8px; 1px neutral dividers; white panels; no stacked border-and-shadow effects. State changes take 160ms and respect reduced motion.

Asset inventory: brand bars and icons use SVG/Lucide; typography uses local system fonts; all navigation, controls, labels, chart bars, sample posts, and ledger rows are semantic React/CSS. No generated bitmap is shipped as UI. The primary Open LinkedIn action is a blue semantic link with an external-link icon.

Do not literalize generation defects: the external picture frame, wifi replacement logo, fabricated version, inconsistent chart values, irrelevant reason labels, and unconditional privacy claim. Use real aggregate data. Sample data lives only in a labeled localhost preview. AI and sync can send data when enabled and must be described accurately.

Signature interaction: changing the threshold updates an explicitly fictional feed preview, explaining the consequence before a user returns to LinkedIn.

Unresolved external checks: real LinkedIn layout, provider credentials, production Supabase, and signed Chrome Web Store publication.
